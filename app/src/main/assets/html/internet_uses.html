Internet Uses

Most features work offline. The internet is used only for:

Maps

Map tiles are downloaded from Google Maps, or from OpenStreetMap when it is the map source. Satellite mode uses more data. OpenStreetMap tiles are cached on the device so revisited areas load without downloading again.

Geocoder

The Android Geocoder converts coordinates into addresses and addresses into coordinates. Each request is usually only a few kilobytes.

The app has no analytics, advertising, crash reporting or license checks.
